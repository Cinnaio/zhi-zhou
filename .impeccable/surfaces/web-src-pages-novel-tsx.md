# Novel 小说详情 · 表面契约

## THESIS

2026-10-02 用户要求直接在正式项目中按已建立的 Claude 风格与现有规则修改小说详情和阅读器。详情延续知舟暖纸书库，以真实封面、作品信息、阅读动作、目录及社区构成连续阅读入口；不制作独立 HTML。

## OWN-WORLD

沿用 `--bg-secondary` 暖灰画布、`--bg-card` 纸面及既有 light/dark 语义色。Hero 透明；只有封面使用共享 `--novel-cover-shadow`。目录与社区纸面复用16px圆角，无容器投影、装饰渐变、水印或英文眉题。`/novel/*` 复用 `header--paper`，保留账户、主题与安全模式交互。

## STORY

真实封面与书名 → 作者、状态、章节数、更新时间 → 分类与简介 → 开始/继续阅读及收藏 → 可搜索目录、已读与上次阅读定位 → 原有前情提要与社区。操作保留原有语义，视觉更新不创造新的 API 或内容分级规则。

## FIRST VIEWPORT

桌面164×246px封面，右侧衬线书名32px / 500 / 1.5、字距-0.02em；信息间距14px，元信息12px。简介14px / 1.85，最大68ch、默认三行，继续提供展开/收起。600px及以下封面88×132px、标题20px；标题与元信息在封面右侧，简介、展开及动作跨全宽。

## FORM

- 最大1080px，区块间距32px；页面上下36px / 64px。600px及以下上下24px / 40px、水平16px、区块间距24px。
- Hero 桌面两列164px与弹性信息列，间距36px；手机88px与弹性列，间距18px。封面10px圆角并独立落影；容器透明。
- 目录与社区纸面16px圆角，桌面28px内边距、手机20px。区标题16px / 600，计数12px；搜索与继续定位位于目录头部。
- 章节目录三列、900px及以下两列、600px及以下单列，桌面列间距24px；每条细底线、最小70px高、上下12px内边距。标题13px / 400 / 1.65、可换行；已读文字弱化，上次阅读项使用轻浅选中态。hover 仅色调反馈，无位移或阴影。
- 手机阅读动作最小40px高。减少动态效果模式关闭本页按钮与条目过渡。

## BEHAVIOR

保留简介溢出检测、展开/收起、收藏、开始/继续阅读、目录搜索、已读标记、上次阅读定位、内容策略及管理员入口。目录与社区仍读取原有 API；评分、评论、前情提要及登录门槛保持原业务实现。空、加载和失败状态沿用现有流程。

## VERIFICATION

本轮类型检查、构建及相关测试通过的结果由主代理汇总。演示 API 回退可用于页面和交互验证，不代表真实后端收藏、评分或评论写入。桌面1280/1440、手机320/390与深色主题截图记录在 `.impeccable/review/reading-redesign`；最终 `final-confirmation.md` 对手机20px内边距和阅读控制区两项修正给出 ship。
