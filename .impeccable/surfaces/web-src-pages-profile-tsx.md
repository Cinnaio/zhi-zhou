# Profile 个人中心 · 表面契约

## THESIS

2026-10-02 用户要求简洁设置页，随后明确否定窄幅方案与书架整体尺寸不匹配。当前个人中心与书架共用1080px外层宽度及24px区块间距，标题与纸面外分类导航沿同一左基线对齐。资料、头像与账户身份在单一暖纸设置面板内组织；书架内部布局与行为保持既有契约。

## OWN-WORLD

沿用既有暖纸语义色和 light/dark 主题，`--bg-secondary` 为画布、`--bg-card` 为设置纸面。纸面16px圆角、无外描边、渐变、阴影或 hover 抬升。主标题使用限定于 Home/Bookshelf/Profile 的既有衬线字体。`.header--paper` 只用于书架与个人中心，账户、安全模式、成人确认、主题与手机导航继续使用现有行为。

## STORY

页头 → 纸面外分类导航 → 单一设置纸面。分类为个人资料、账户安全、登录设备，使用 `aria-pressed`，不声明 ARIA tabs。非当前内容使用 `hidden` 隐藏但保持挂载，切换保留草稿。纸面内先显示共用头像、名称、用户名及角色/状态徽标，再显示当前设置内容；注册与最近登录记录位于纸面脚注，管理员入口按角色显示。个人资料中的头像操作在 DOM 中位于字段之前，不使用 CSS order；共用身份头像直接显示选中文件的预览，不另设头像预览或重复简介。

## FIRST VIEWPORT

主标题32px / 500 / 1.5、字距-0.02em，600px及以下1.55rem；说明14px / 1.8。反馈 `.profile-message` 位于同一页头描述下方，使用正常文档流；空内容隐藏，13px / 1.8、上间距12px、长错误允许任意位置换行。保留 `role="status"` 与 `aria-live="polite"`，失败不能覆盖标题或身份区域。

## FORM

- 个人中心与书架共享最大1080px、24px区块间距。桌面页面上下48px / 64px；600px及以下上下28px / 40px、水平16px。分类导航在纸面外，与标题及纸面外缘对齐。
- 单一设置纸面桌面内边距32px，600px及以下20px；设置内容为撑满宽度的纵向 flex，内部面板无独立卡片或内边距，隐藏区 `display:none`。
- 身份区48px头像 + 弹性文字、间距14px；600px及以下40px头像、间距12px。名称16px / 600，用户名12px，徽标11.2px；名称与用户名可换行。身份区底部内边距与外间距各28px、手机各24px，并有单条分隔线。手机徽标位于文字下方。
- 分类按钮14px、最小44px高、桌面间距28px，无额外底部外间距；选中为600字重、正文色及2px强调色下划线。600px及以下按钮13px、间距20px。键盘焦点使用强调色2px外轮廓、4px偏移。
- 头像操作显示13px的“头像”标签，桌面为160px标签列 + 弹性操作列、间距32px、下方外间距28px。资料及安全字段同用160px + 弹性内容列、间距32px，字段行下方间距24px、标签顶部内边距12px。600px及以下均改单列、间距10px，字段标签顶部内边距0。选择/删除按钮始终提供，上传按钮仅选中文件或上传中显示；隐藏文件输入 `tabIndex={-1}`，操作组自然换行。
- 面板标题16px / 600，字段标签13px。输入14px，600px及以下16px；textarea最小96px、行高1.7，可竖向调整。按钮13px / 500、10px圆角、无阴影；手机最小40px。
- 脚注11.2px / 1.8，顶部20px内边距、24px外间距和单条分隔线；记录自然换行，桌面管理员链接右对齐，手机随记录排列。
- 设备列表最大高300px、内部滚动，桌面32px图标 + 弹性内容 + 动作列；手机28px图标列，注销按钮落在内容列下。设备名13px可换行、详情11.2px；当前设备标记及禁止注销当前设备保留。
- reduced motion 下关闭页面卡片、按钮与分类导航过渡。
