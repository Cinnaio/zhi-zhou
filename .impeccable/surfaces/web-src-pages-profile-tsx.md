# Profile 个人中心 · 表面契约

## THESIS

2026-10-02 用户要求按现有 Claude 风格直接修改正式页面，不制作 HTML 预览。个人中心先说明当前身份，再提供资料、头像、密码与设备设置；清晰的阅读顺序与克制的纸面层次延续首页和书架。

## OWN-WORLD

沿用既有暖纸语义色和 light/dark 主题，`--bg-secondary` 为画布、`--bg-card` 为卡片。卡片16px圆角、无外描边、渐变、阴影或 hover 抬升；主标题允许限定于 Home/Bookshelf/Profile 的既有衬线字体。`.header--paper` 只用于书架与个人中心，账户、安全模式、成人确认、主题与手机导航继续使用现有行为。

## STORY

页头 → 身份摘要 → 设置网格。身份摘要包含头像、名称、用户名、角色/状态、简介以及注册/登录/角色读数；管理员入口按角色显示。设置顺序为个人资料、头像、修改密码、登录设备，保留原字段、操作与错误反馈。

## FIRST VIEWPORT

主标题32px / 500 / 1.5、字距-0.02em，600px及以下1.55rem；说明14px / 1.8。反馈 `.profile-message` 位于同一页头描述下方，使用正常文档流而非定位浮层；空内容隐藏，13px / 1.8、上间距12px、长错误允许任意位置换行。保留 `role="status"` 与 `aria-live="polite"`，失败不能覆盖标题或身份区域。

## FORM

- 内容最大1200px，桌面页面上下48px / 64px、区块间距32px；600px及以下上下28px / 40px、水平16px、间距24px。
- 身份卡与设置卡内边距28px、手机20px。身份主列为72px头像 + 弹性文本，间距24px；手机56px头像、间距16px，头像预览保持64px。
- 名称20px / 600，用户名、记录标签12px，徽标11.2px。简介14px / 1.8、最大65ch；姓名、用户名与简介可换行。身份读数放同一区域，顶部20px内边距、24px外间距、单条分隔线，数值13px正常字重，不另加统计卡片。
- 设置桌面网格 `minmax(0,1.1fr) minmax(0,1fr)`、间距20px、顶部对齐；800px及以下单列。面板标题16px / 600，字段标签13px，字段间距18px。输入14px，600px及以下16px；textarea最小100px、行高1.7，可竖向调整。
- 按钮13px / 500、10px圆角、无阴影；手机最小40px。头像选择区手机纵向排列，操作组自然换行。
- 设备列表最大高300px、内部滚动，桌面32px图标 + 弹性内容 + 动作列；手机28px图标列，注销按钮落在内容列下。设备名13px可换行、详情11.2px；当前设备标记及禁止注销当前设备保留。
- reduced motion 下关闭页面卡片与按钮过渡。

## BEHAVIOR

保留未登录返回 `/auth` 并记录 `/profile`、会话加载、资料保存、密码显示/校验/修改、头像选择/预览/上传/删除、设备注销、退出其他设备与退出登录。真实数据和 API 继续使用原流程；提交禁用状态及现有错误文案语义不由视觉重写。
