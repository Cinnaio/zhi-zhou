# 共享章节插图

管理员在阅读工具栏点击「章节插图」，进入插图模式。在章首、段落之间或章尾选择位置，上传或粘贴图片，填写可选图注、选择展示宽度，预览后保存。划选正文后的「在本段后插图」也能打开添加窗口。

上传支持 JPG、PNG、WebP、AVIF，最大 10MB。服务端验证真实图像格式、限制解码像素，校正方向并转换为 WebP；不会保存 EXIF。首版使用静态图片。

保存立即生效，其他读者重新加载章节即可看到。已有插图支持替换、编辑图注/宽度、移动和删除。操作后 12 秒内可以撤销；版本冲突不会覆盖其他管理员的修改。阅读设置中的「插图」默认显示，读者可以独立隐藏。手机插图开关保持面板打开，方便比较两种布局。

章节管理的编辑窗口提供「预览与管理插图」，使用同一份插图数据，列出插图及段落摘要。插图独立保存；取消章节编辑不会撤销已保存的插图。新增章节或修改正文时，需先保存正文，再打开插图管理。

## 位置与权限

插图不写入文字正文，不增加 `<p>`，不改变字数、段评编号或原始来源数据。图片与图注不参与正文广告清洗。

段落定位记录正文文本、相邻段落和源段落锚点。正文变化后优先跟随唯一的相同段落；重复段落需有唯一的相邻上下文。无法确认的位置停止在正文展示，并在管理员的「位置待确认」列表保留，支持重新定位或删除。章首/章尾插图始终固定在对应边界。

上传、编辑、移动、删除与撤销只允许管理员。图片列表和二进制读取遵守所属章节的内容权限，并禁止浏览器缓存。前端切换章节、账号或内容模式时释放图片请求及 Blob URL。

图片按比例预留空间，接近视口才读取图片文件。点击大图不会触发翻页；插图模式暂停自动滚动和点击翻页。正文高度变化会更新分页数量。

## 数据与发布

数据库迁移 `049_chapter_illustrations.sql` 创建 `chapter_illustrations` 和 `chapter_illustration_assets`。图片素材独立存储；替换和移除保留旧素材以便撤销。删除章节时清理关联插图和素材。现有全库备份包含这两张表，恢复影响报告分别归入章节和图片资源。

发布前执行 `npm run db:migrate`，然后构建并按现有部署流程更新前后端。代码实现本身不自动修改运行中的数据库或重启服务。
