# 账户与注册剩余三页设计预览

预览文件：`previews/account-registration-audits-claude.html`。通过侧栏或手机顶部导航切换注册与邀请码、登录审计、操作审计；URL hash 支持 registration / audit / operation。

沿用已确认的用户管理与共享设计规范：暖纸面画布、无外描边白色面板、20px 面板圆角、40px 控件、280px 搜索、36px 文字头像、11px 状态胶囊和 76px 宽松列表行距。具体日期与时分分层展示。手机使用连续记录卡片，正文信息与字段标签成对排布。

注册设置采用三个单选项，明确当前生效方式与未保存草稿；邀请码生成、复制、停用、失效清理集中在目录中。登录列表合并结果与原因、IP 与设备摘要，详情保留完整 User-Agent。操作列表合并动作与目标范围、操作 ID 与 HTTP 状态，详情保留重放次数、错误及创建/更新/完成时间。

可交互内容：三页切换、明暗主题、搜索、状态筛选、15/20/50/100 行分页、记录详情、注册方式保存、示例邀请码生成和复制、停用与清理确认。新增的搜索与详情组织属于预览提案；实际接入时需核对后端支持，不在本轮实现。

所有内容均为静态示例数据，地址使用文档专用 IP 范围，邀请码带 DEMO 前缀；无 API 请求，重新加载后还原示例。现有项目源码、共享库和设计规范未修改。

验证：浏览器检查三页桌面及 390px 手机布局无横向溢出；验证搜索、筛选、分页、详情、注册设置保存与邀请码生成；检查明暗主题。截图位于同级 previews 目录的 account-*-claude-*.png。脚本通过 node --check，静态 HTML ID 无重复。
