# 流量分析落地记录

基于 `docs/previews/traffic-analysis-claude.html` 将流量分析落到实际管理后台。沿用共享后台字体、暖色画布、奶茶色强调、无外描边无阴影的 20px 圆角面板、共享页标题与弹窗组件。保留流量分析入口；已删除的运营概览、内容分析旧链接自动转入流量分析，保留其他 URL 参数。

## 实际功能

- 统一 7 / 30 / 90 日范围，范围写入 URL；图表、地区、设备、来源和 CSV 使用同一数据快照。
- PV / UV 图表切换；上一周期趋势虚线与总量变化；上期为零时明确显示无访问，不产生无穷百分比。
- 每日明细包含零访问日期；对比时列出对应上期日期和数据；峰值提示按真实每日 PV 计算。
- 地区展示前七个已识别地区、其余已识别地区合计和未识别访问，所有占比以全部 PV 为分母；没有地区信息不等于没有访问。
- 地区、设备、来源行打开共享详情弹窗，展示本期 PV、占比和统计口径。
- 导出 UTF-8 BOM CSV：本期和上期总量、逐日明细、维度汇总；保留周期去重 UV，字符串防止公式注入。
- 刷新失败保留同范围的上次数据并提供重试；切换范围不显示旧范围数据；迟到的响应不能覆盖最新范围。

## 接口与口径

新增管理员接口 `GET /api/admin/site/traffic?days=7|30|90`，默认七日，其他范围返回 400，保留管理员权限校验并禁用响应缓存。旧 `GET /admin/site` 与公告更新接口保留兼容其他客户端。

查询使用只读 Repeatable Read 事务，使周期总量、每日数据和维度读取同一快照。按 `Asia/Shanghai` 划分自然日，包含今日截至查询开始时刻；上期从本期开始向前移动完整日数，并截至相同时刻，保持相同经过时长。半开时间区间排除未来事件。周期 UV 直接对整个范围去重，不能用每日 UV 相加。

没有新增个人事件或数据库迁移，也没有加入缺乏事件支持的跳出率、留存或阅读完成率。

## 验证

- PostgreSQL 语义测试：跨日去重、北京时间零点、等时长上期、零日期补齐、超过排行上限的地区总量、空周期。
- 路由测试：匿名访问 401、范围白名单、默认七日、no-store。
- 前端测试：旧链接归一、刷新、统一范围、失败保留数据、维度弹窗、比较、下载调用、空数据禁用导出、请求竞态；CSV 内容及转义。
- 前后端类型检查与生产构建通过。定向 ESLint 无错误，保留一项现有的 effect 加载状态模式警告；构建保留既有 chunk 大小提示。
- 真实已登录浏览器中，七日统计 132 PV / 2 UV；三十日统计 257 PV / 9 UV，比较为 PV -21.9%、UV +80.0%，地区识别率 27.2%（验证时快照）。
- 桌面、390px 手机布局检查；手机展开三十日明细、切换 UV 后无页面横向溢出。
- CSV 内容生成及 Blob/下载点击路径通过自动测试；实际浏览器下载事件监听超时，因此未确认文件落盘。
