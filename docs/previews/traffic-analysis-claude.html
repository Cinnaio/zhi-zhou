统计口径与隐私说明

PV 为访问记录数；UV 按浏览器随机标识的哈希在选定周期内去重，不能将每日 UV 相加作为周期 UV。当前来源为直接、搜索、外部、站内四类。访问量不等于阅读完成量，也不用于推断付费转化。仅显示聚合结果，不展示个人访客标识、IP 或完整来源地址。

本页为独立交互方案，全部数据为示例，没有连接项目 API。30/90 日、上一周期对比与完整地区覆盖率需要补充后端支持。

这版增加了什么

以看清变化为主，把读数、筛选和明细放在同一工作区域。保持共享的 20px 页标题、白色无描边面板与奶茶棕，不引入独立大指标卡。

  • PV / UV 切换、每日明细、CSV 导出优先落地
    可使用现有近 7 日聚合数据实现；导出仅包含聚合统计。UV 周期总数读取服务端去重结果。
  • 7 / 30 / 90 日与上一周期对比需接口扩展
    为趋势、地区、设备、来源采用统一时间窗口，分别计算本期与上期的去重访客；明确统计时区。
  • 地区识别覆盖率需完整口径
    当前接口地区查询只取前 8 类，可能漏掉未识别记录。应独立返回全量未识别数，不能用前 8 类之和计算覆盖率。
  • 访问时段分布后续考虑
    已有访问时间可按小时聚合；用于观察高峰。先补统计时区，再考虑异常波动提示。

暂不加入留存、跳出率、阅读完成率或转化漏斗：现有访问记录缺少会话、阅读完成和目标事件，直接展示会制造错误结论。这里也不恢复已删除的运营概览和内容分析。
