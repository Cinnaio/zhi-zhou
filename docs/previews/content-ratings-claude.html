分级管理

维护作品分级与判定依据，让每一次修改都有据可查。

分级与审核口径

未标注不等于一般。 R18 对应限制级；规则与 LLM 只提出限制级或继续未标注的判断，不自动标为一般。规则批准前预览影响范围，模型建议经人工审核才可修改分级；人工修改必须填写理由并保留审计记录。

作品分级账本

规则候选

从人工判定中沉淀规则，先核对命中作品，再决定是否启用。

批准仅影响命中的未标注作品，保留一般作品及已人工确认的分级。

LLM 分级建议

只分析未标注作品的元数据，逐条保留证据与人工决定。

模型建议不会自动写入分级。批准“继续未标注”也不会将作品标为一般。
