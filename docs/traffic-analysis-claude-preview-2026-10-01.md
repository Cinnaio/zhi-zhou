# 流量分析 HTML 预览（2026-10-01）

预览文件：[traffic-analysis-claude.html](previews/traffic-analysis-claude.html)。本地预览地址为 `http://localhost:8768/traffic-analysis-claude.html`，也可以直接在浏览器打开单文件。全部数据为示例，无远程依赖，不请求项目 API。

## 设计方向

基于当前流量分析的访问趋势、地区、设备和来源结构，继承 DESIGN.md 的暖灰画布、奶茶棕、系统字体、20px 页标题、16px 面板标题和20px白色无描边面板。读数放在所属图表标题区，时间筛选在工作区上方，避免新增独立大指标卡。地区、设备和来源宽屏并列，中屏两列，手机纵向排列。

趋势面板包含 PV / UV 切换、上一周期曲线、日高点说明和可展开的每日明细。支持图表数据点的指针及键盘查看、维度统计说明、主题切换，以及正常、无数据、地区未识别和刷新失败四种预览状态。维度点击仅查看数量及口径，不伪装成尚不存在的多维交叉筛选。

本页延续仅保留流量分析的站点运营导航。此次新增的是独立预览及说明，之前移除运营概览与内容分析的项目改动仍为单独待提交变更。

## 可新增功能与落地顺序

| 优先级 | 功能 | 作用与数据要求 |
| --- | --- | --- |
| 第一批 | PV / UV 指标切换 | 用现有每日浏览量、每日去重访客实现；单独查看 UV 时使用相应纵轴。 |
| 第一批 | 每日明细、日期补零、高点提示 | 让图表可核对，使用现有近7日趋势；无记录日期补零，高点只描述数量，不推断异常原因。 |
| 第一批 | 聚合 CSV 导出 | 导出当前趋势、周期总数与维度聚合；周期 UV 直接使用服务端去重数，不相加每日 UV。 |
| 第二批 | 7 / 30 / 90日及上一周期对比 | 当前接口固定近7日。需增加统一范围参数、明确统计时区，并让趋势和各维度采用同一窗口；两期 UV 分别去重。 |
| 第二批 | 完整地区识别率、其他地区 | 当前地区查询仅返回前8类，ZZ可能不在结果中。需独立返回全量未知地区数量与其他地区合计；按周期全部PV计算覆盖率。 |
| 后续 | 访问时段分布 | 已有访问时间可按小时聚合；先统一时区，再考虑高峰或波动提示。 |

不建议现阶段加入留存、跳出率、阅读完成率、转化漏斗：现有访问记录没有完整会话、阅读完成和目标事件，不能由 PV/UV 推断这些指标。访问来源是粗粒度分类，也不能当作营销渠道归因。

以上判断依据 [当前页面](../web/src/pages/admin/SiteOperationsTab.tsx)、[接口类型](../web/src/lib/api.ts) 与 [站点聚合路由](../api/src/routes/site.ts)。其中 `site_visits` 记录访问时间、浏览器标识哈希、路径、地区及设备/来源分类；现有路由按近7日聚合，地区排行限制8类。

## 统计和示例边界

示例近7日为2026/09/25至2026/10/01，共1,846 PV和312周期UV。每日UV存在跨日重复；周期UV不是每日UV之和。30/90日、同期曲线和地区覆盖率仅展示建议功能，不表示现行接口已支持。对比曲线使用示例数据派生，不作为真实上期记录。

地区百分比以全部PV为分母，未识别数单独列出；无地区代码时显示全部未识别，不显示为零访问。来源解释保留“站内跳转也会产生访问记录”。页面只展示聚合信息，不展示访客哈希、IP或完整来源地址。
