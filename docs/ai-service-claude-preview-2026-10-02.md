# AI 服务 Claude 风格预览

入口：`docs/previews/ai-service-claude.html`。单文件包含 CSS、图标、示例数据与演示脚本，打开本地文件即可使用，也可通过预览服务器访问。

## 页面范围

对应当前 `AiTab` 的五个子页面，保留 AI 任务在任务中心、调用与用量在运行监控的导航归属。

| 页面 | 预览设计 |
| --- | --- |
| AI 创作 | 续写优先，续写/新写与单章/多章切换；目标、基线、内容尺度和小说分析靠前；长分析折叠；情节方向、大纲、提交内容与草稿产出相连；侧栏呈现作品上下文、未发布草稿和任务回执。 |
| 封面生成 | 左侧视觉方向与生成设置，右侧候选选择、大图比较、采纳与弃用；当前封面和历史保留在候选下方；更换作品清空旧候选，采纳前确认；本地图片只预览不上传。 |
| 已生成内容 | 搜索、类型/状态筛选、批次展开、选择和删除确认、章节审阅与草稿编辑/发布；移动端使用连续卡片，保留字段标签。 |
| AI 配置 | 文本与图像连接分别呈现，读者策略和服务用量独立分组；演示连接检查；编辑后启用保存，撤销可恢复本次基线；不显示真实密钥。 |
| 参数调优 | 前情提要、回顾总结、AI 创作、生图与封面、任务与运维、审计六组设置；桌面分组导航、手机横向分组入口；提示词按需展开；固定保存区域显示编辑状态。 |

## 共享设计依据

沿用项目暖灰画布、白色无外描边面板、棕色品牌操作、12px 控件和 20px 大面板圆角。页标题 20px、面板标题 16px、正文与辅助字阶不随面板放大。数值贴近其对应内容，不增加统计卡。状态标签采用浅色语义背景。白天与深色主题均使用同一组语义变量；尊重减少动效偏好。

此预览不修改 `DESIGN.md`、共享库或实际业务页面。封面使用 CSS 版式示意，不代表模型实际生成图像。所有生成、测试连接、保存、发布、删除、恢复操作均只修改当前预览的示例状态，没有任何项目 API 请求。页面切换保留已输入的创作内容；刷新页面重置示例状态。
