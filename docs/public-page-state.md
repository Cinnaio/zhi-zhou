# 公开整页状态与访问门禁

共享实现：`web/src/components/PageState.tsx`；共享样式：`web/src/styles/page-state.css`；尺寸语义变量：`web/src/styles/tokens.css`。视觉契约以 `DESIGN.md` 的 Full-page State 为准。

## 使用边界

| 场景 | 实现 | 导航与内容区域 |
| --- | --- | --- |
| 小说详情、阅读器被内容策略拦截 | `ContentRestrictionNotice` → `PageState` | 无导航，消息居中；不渲染被保护内容 |
| 小说、章节未找到 | `PageState` | 无导航，提供返回首页 |
| 后台未登录或非管理员 | `AdminGate` → `PageState` | 不渲染后台外壳；保留原鉴权、登出与返回地址 |
| 首页安全模式隐藏部分作品 | `ContentRestrictionNotice compact` → `PageState inline` | 保留导航与列表，仅显示局部提示 |
| 首页搜索无结果、书架无记录 | 既有列表空态 | 保留筛选、分类、导航 |
| 后台面板加载失败／无数据 | 既有 `AdminEmptyState`、`InlineError` | 保留管理外壳与恢复操作 |
| 登录、安装、表单校验 | 既有页面与表单反馈 | 不使用整页状态替换可操作表单 |

```tsx
<PageState
  title="小说未找到"
  description="请检查链接是否正确，或返回首页浏览其他小说"
  icon={<BookOpen />}
  actions={<Link to="/" className="btn btn--primary">返回首页</Link>}
/>
```

`icon`、`actions` 与补充说明 `children` 均可选；图标只表达当前状态，不用于额外装饰。`inline` 变体使用 h2 与 status；整页使用 main 与 h1。

## 布局与恢复契约

整页状态在正常 `Layout` 内通过 `PageLayoutContext` 于绘制前撤下 `SiteHeader` 和 `SiteNotice`，卸载时恢复。阅读器与后台门禁本身处于独立路由，没有该上下文也可直接使用。不要用覆盖层遮住仍存在的导航，不用路由字符串或 DOM 查询推测状态。

消息组在完整视口居中，使用主题暖灰画布，无卡片边框、投影或嵌套提示卡。最小高度而非固定高度保证长文案、浏览器缩放和小屏横向设备仍可滚动看到全部操作。

内容拦截仅在站点允许时显示解锁入口。游客登录携带路径与查询参数；登录用户调用原模式切换函数，仍须通过成年确认及 Turnstile。站点禁用成人模式时明确说明关闭状态，只显示返回入口。adult 状态仍被接口拒绝时提供重新验证，不在展示组件内自动授予权限。

后台切换账号保留异步登出与禁用状态，完成后再导航到登录页，避免已有登录状态让 Auth 自动回跳。引导入口仅在 setup 状态确认需要初始化时显示。

## 检查清单

- 整页状态无公开导航；返回或解除拦截后导航及公告正常恢复。
- 游客、已登录、安全／成人模式、站点禁用四类内容入口正确。
- 权限门禁不挂载受保护管理内容；切换账号期间不可重复点击。
- 明暗主题、自定义强调色、键盘焦点、44px 操作高度与窄屏换行遵循共享样式。
- 不把暂时加载失败、真实空列表、资源缺失或权限拒绝混为一种状态；接口分类仍由业务层负责。
