# 测试隔离与分级视图修复

## 问题与行为

- 普通后端测试此前读取项目 `.env`、运行时配置、本地备份配置及继承的代理。部署主密钥启用备份维护中间件后，其独立 PostgreSQL 连接池会连接测试占位主机 `test`，绕过 PGlite 注入并使业务路由返回 500。
- 新增统一测试 setup，在应用模块加载前为每个测试文件设置独立临时配置目录，清除部署数据库、密钥及代理变量，结束后清理目录。生产维护中间件保持原实现；真实 PostgreSQL/SFTP 集成测试仍从专用集成变量取得连接。
- 书源同步测试同时提供目录 HTML 和账号会话夹具，不依赖部署账号。
- AI SSE 测试的上游尾片原本在 40ms 后发送，而任务 SSE 每 100ms 轮询，负载下会错过中间状态。现在客户端实际收到中间状态后才释放尾片，保留实时更新与最终持久化断言。
- 分级页面离开账本时取消搜索防抖，不再触发后台账本读取；离开视图或更换查询后使旧请求结果失效。返回账本保留搜索输入并重新查询。
